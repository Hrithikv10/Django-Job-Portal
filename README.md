# Job Portal System – Web Application

A full-stack Job Portal System built using **Python, Django, MySQL, and Bootstrap**, designed to support role-based access for candidates and companies with complete job posting and application workflows.

---

## 📌 Project Overview

The Job Portal System is a web application that enables companies to post job openings and manage applications, while candidates can search for jobs and apply online.

The project focuses on real-world recruitment workflows, secure authentication, relational database design, and backend business logic using Django.

---

## 🚀 Key Features

### 🔐 Authentication & Security
- User signup and login
- Role-based access for Candidates and Companies
- Email verification during registration
- OTP-based password reset
- Secure authentication using Django’s built-in auth system

---

### 👤 Candidate Features
- Browse available job listings
- Search jobs based on criteria
- View detailed job descriptions
- Apply for jobs
- Track job application status

---

### 🏢 Company / HR Features
- Company dashboard with job statistics
- Post new job openings
- Update and delete job postings
- View applied candidates
- Track application status
- Email notifications for job applications

---

### 📊 Job & Application Workflow
- Job posting by companies
- Job search and filtering
- Job application submission
- Application status tracking
- Automated email notifications

---

## 🛠 Tech Stack

- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** MySQL  
- **ORM:** Django ORM  
- **Authentication:** Django Authentication System  
- **Email:** SMTP / Django Email Backend  

---

## 🗄 Database Design

- Relational database design using MySQL
- Proper foreign key relationships between users, jobs, and applications
- CRUD operations implemented using Django ORM
- Optimized queries for job listings and application tracking
